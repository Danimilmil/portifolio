# Portfólio — Daniel Dias

Site estático publicado na Vercel.

## SEO incluído
- Título e descrição da página.
- Canonical e metadados Open Graph/Twitter.
- Dados estruturados Schema.org (`Person`).
- `robots.txt` com acesso ao OAI-SearchBot.
- `sitemap.xml` com a página inicial.
- Arquivo de verificação do Google Search Console.

## Publicação
Faça commit e push para o repositório conectado à Vercel. Depois do deploy, teste:

- `/robots.txt`
- `/sitemap.xml`
- `/google8271b50d0a7cbe97.html`

No Google Search Console, envie `sitemap.xml` e solicite a indexação da página inicial.

SEO e indexação não garantem posições específicas no Google nem recomendações no ChatGPT.
